About the Popover API

The popover attribute creates a native browser overlay that:

  • Appears on top of all other content (top layer)
  • Automatically handles backdrop clicks to close
  • Supports light dismiss (click outside or press Escape)
  • No z-index required - always on top
  • Perfect for fullscreen editor interfaces

Browser support: Chrome 114+, Edge 114+, Safari 17+, Firefox (in development)

💻 JavaScript Controlled Popover

Controlled via JavaScript

This popover uses popover="manual" for full programmatic control: 

// Open popover
element.showPopover();

// Close popover
element.hidePopover();

// Toggle popover
element.togglePopover();

// Check state
element.matches(':popover-open');

// Listen to events
element.addEventListener('toggle', (event) => {
  if (event.newState === 'open') {
    console.log('Popover opened!');
  }
});
Use Case for Compositor4:

Manual mode lets us:

  • Initialize canvas before showing
  • Prevent accidental closes
  • Sync state on open/close events
  • Control visibility programmatically
